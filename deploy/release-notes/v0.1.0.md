t3opt is a second route to a t3code server for very bad mobile links: a home-screen web app on the phone, and a sidecar beside a stock t3 server that syncs it over a WebRTC data channel, newest text first. The plan is in [the map issue](https://github.com/djosh34/t3-optimizations/issues/1).

This first release runs against t3 v0.1.7. What the chaos lab measured on it, against t3code's own v0.1.7 web client on the same links:

- 50 seeds of 2G-like links: replies completed 48 of 50 against 31 of 50; median longest freeze 13.7 s against 49.8 s ([#58](https://github.com/djosh34/t3-optimizations/issues/58)).
- At 50% loss, the newest text at most 4.2 s behind. At 70% loss on an open connection, prompts confirmed within 10 s on 7 of 8 seeds ([#46](https://github.com/djosh34/t3-optimizations/issues/46)).
- Open: a cold start at 70% loss does not finish in 15 minutes, and the other open defects listed on #46 and #58.

## What is in it

- `t3opt-sidecar-linux-x86_64`, `t3opt-sidecar-linux-arm64`: the sidecar, static binaries.
- `t3opt-web.tar.gz`: the home-screen web app (the t3code v0.1.7 web client with the t3opt adapter), served by the sidecar.
- `t3opt-server.service`, `t3opt-sidecar.service`: user services. `t3opt-server` runs the stock t3 v0.1.7 release with its own data in `~/.t3opt`, on localhost only; the sidecar is its client.
- `install.sh`, and `SHA256SUMS` of every file.

## Install

On a Linux host on a tailnet, as the user who runs the services:

```sh
curl -fsSLO https://github.com/djosh34/t3-optimizations/releases/download/v0.1.0/install.sh
T3OPT_RELEASE=v0.1.0 bash install.sh
```

It installs t3 v0.1.7 from t3code's release and these files under `~/.local/share/t3opt`, starts both services, and adds one `tailscale serve` route, `https://<host>:12443` to the sidecar. WebRTC uses UDP 12444 on the tailnet address. It leaves `~/.t3`, an official t3code service and every other route alone.

Then mint a pairing code with `~/.local/share/t3opt/t3-0.1.7/t3 pair --base-dir ~/.t3opt` and enter it at `https://<host>:12443` on the phone.

[deploy/README.md](https://github.com/djosh34/t3-optimizations/blob/v0.1.0/deploy/README.md) has the details: paths, pairing, how to stop and remove it, and the live check.
